# 🧟 Zombie Survival Game

My very first Python project! A text-based survival game where you manage resources and try to survive a zombie apocalypse.

## 🎮 Features
- **Zombie Raids:** Choose to Attack, Run, or Hide.
- **Scavenging:** Risk spending days to gather extra ammo and food.
- **Resource Management:** Keep track of your HP, Food, Ammo, and Miles left.

## 🚀 How to Play
1. Make sure you have Python installed on your computer.
2. Download or clone this repository.
3. Run the script in your terminal:
```bash
   python "Survival Game.py"
